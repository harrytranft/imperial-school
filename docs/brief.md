
# Job Brief: Phát triển Ứng dụng Quản lý Học sinh "Cung Đình"

## Thứ tự thực hiện:
1. **Giai đoạn 1: Setup Foundation**
   - Cài đặt cấu trúc thư mục, định nghĩa Types và Constants.
   - Xây dựng Layout mang phong cách hoàng gia.

2. **Giai đoạn 2: Quản lý Dữ liệu**
   - Xây dựng chức năng Import CSV để khởi tạo danh sách học sinh.
   - Quản lý danh sách Lớp và Học sinh trong LocalStorage.

3. **Giai đoạn 3: Core Logic (Gamification)**
   - Viết logic tính Rank theo giới tính và mốc 50 điểm.
   - Xây dựng Modal cộng/trừ điểm nhanh (Quick Action).

4. **Giai đoạn 4: Trải nghiệm người dùng (UX)**
   - Tích hợp Gemini API để tạo nội dung "Thánh chỉ" khi thăng/giáng chức.
   - Thêm hiệu ứng âm thanh/hình ảnh khi có thay đổi cấp bậc.

5. **Giai đoạn 5: Dashboard & Thống kê**
   - Hiển thị bảng xếp hạng (Top Cung Đình).
   - Lọc học sinh theo lớp và rank.
